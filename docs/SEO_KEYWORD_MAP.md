# GERKINK SEO Keyword Map & Architecture

## Overview & Philosophy
Modern search engines (Google RankBrain, MUM, and semantic entity graphs) do not rank pages based on raw `meta keywords` lists. Search engines index and rank pages based on:
1. **Semantic Relevance & Intent Matching:** Clear alignment between search intent (informational, commercial, transactional) and on-page content.
2. **Topical Authority:** Clear parent-child information hierarchy linking collections, categories, and individual products.
3. **On-Page Natural Language Integration:** Placement of search terminology in `<title>`, `<meta description>`, `<h1>` and `<h2>` headings, descriptive copy, image `alt` attributes, and anchor text.

## 3. Practical On-Page Optimization Guidelines

### 1. Natural Heading Hierarchy
- Ensure each page has exactly one `<h1>` containing the primary topical entity or brand hook.
- Use `<h2>` elements for logical subtopics (e.g., `Fabric & Heavyweight GSM Specifications`, `Atelier Custom Workflow`, `Customer Lookbook`).

### 2. Product Image Alt Text Blueprint
Never use generic filenames (e.g., `IMG_001.jpg` or empty `alt=""`).
- **Good:** `alt="GERKINK God's Plan heavyweight graphic streetwear t-shirt front view"`
- **Good:** `alt="GERKINK custom design studio embroidery sample detail"`
- **Bad:** `alt="shirt"` or `alt="streetwear luxury graphic clothing fashion buy online discount"` (Keyword stuffing).

### 3. Internal Anchor Text
Use descriptive link labels instead of "Click Here" or "Read More":
- **Use:** `"Explore Custom Designs"` instead of `"Click here to design"`.
- **Use:** `"Browse Society Fuckers Collection"` instead of `"View more"`.
- **Use:** `"Shop Heavyweight Graphic Tees"` instead of `"Buy now"`.

### 4. Technical Search Signals
- `sitemap.xml` automatically syncs all canonical public URLs and images.
- `robots.txt` explicitly disallows private user accounts (`/account/`, `/admin/`, `/checkout/`, `/cart/`) while granting full crawl access to public landing and product pages.
- JSON-LD Structured Data (`WebSite`, `Organization`, and `Product`) provides rich snippet data (pricing, availability, brand, currency).
